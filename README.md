# 个人学术网站

费孝妍（Xiaoyan Fei）的个人学术网站，使用 GitHub Pages 托管：

**https://fei-2006.github.io**

我目前在美国明尼苏达大学双城分校地理、环境与社会系就读本科，研究兴趣是遥感与环境研究，常用 GIS、深度学习、街景影像和空间统计方法。

## 文件结构

```
index.html                     # 整个网站（HTML、CSS 和少量 JavaScript），支持中英文切换
Xiaoyan_Fei_Academic_CV.pdf    # 网站上链接的学术简历
assets/                        # 网站使用的照片和图表
```

网站是单个静态页面，不需要编译：修改 `index.html` 或 `assets/` 里的文件并推送后，GitHub Pages 会自动更新。
