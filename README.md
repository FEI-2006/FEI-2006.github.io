# Personal Academic Website

Source code for the personal academic website of Xiaoyan Fei, hosted with GitHub Pages:

**https://fei-2006.github.io**

I am an undergraduate student in the Department of Geography, Environment and Society at the University of Minnesota Twin Cities, interested in remote sensing and environmental research using GIS, deep learning, street-level imagery and spatial statistics.

## Structure

```
index.html                     # the whole site (HTML, CSS and a little JavaScript), with an English/Chinese toggle
Xiaoyan_Fei_Academic_CV.pdf    # CV linked from the site
assets/                        # photos and figures used on the site
```

The site is a single static page, so no build step is needed. Edit `index.html` or the files in `assets/`, push, and GitHub Pages updates the site automatically.
