# Xiaoyan Fei — Academic Website

Source code for my personal academic website, hosted with GitHub Pages:

**https://fei-2006.github.io**

I am an undergraduate student in the Department of Geography, Environment and Society at the University of Minnesota, interested in remote sensing and environmental research using GIS, deep learning, street-level imagery and spatial statistics.

## Structure

```
index.html                     # the whole site (HTML, CSS and a little JavaScript)
Xiaoyan_Fei_Academic_CV.pdf    # CV linked from the site
assets/                        # photos and figures used on the site
```

The site is a single static page with an English/Chinese language toggle. No build step is needed: edit `index.html` and push, and GitHub Pages republishes it automatically.
